# 动漫人格测试

回答 12 道日常小问题，测出你是哪位动漫角色。

- 20 位角色，9 部作品：进击的巨人、命运石之门、火影忍者、死亡笔记、海贼王、鬼灭之刃、咒术回战、名侦探柯南、凉宫春日的忧郁等
- 结果页含匹配度、角色台词、性格标签、热情 / 理性 / 温柔 / 自由四维条、闪光点与副人格
- 纯前端单文件页面，直接打开 `index.html` 即可测，无需服务器

## 在线访问（GitHub Pages）
